# Дополнительные запросы бэкенда

Слоты ниже называют логическую CRUD-операцию и указываются в `view.source`. Базовый CRUD выполняй прямым доступом к БД и бэкенду продукта. Отдельный маршрут из карты используй только для дополнительной связи или составного запроса, уже реализованного на бэкенде; его отсутствие не блокирует обычный CRUD.

| Слот | Намерение | Аргументы |
|---|---|---|
| `list` | Read + `group` | `entity`, `filters`, `page` |
| `get` | Read + `element` | `entity`, `id` |
| `create` | Create + `element` | `entity`, `payload` |
| `update` | Update + `element` | `entity`, `id`, `payload` |
| `delete` | Delete + `element` | `entity`, `id` |

`page` относится только к `list`, а не к `intent`. `create` не принимает существующий id; остальные Write работают только с одним id.
